# EAMNet API 性能测试记录

## 1. 测试目标
测试 EAMNet 模型预测接口 POST /predict 在不同并发用户数下的响应时间和吞吐量。

## 2. 测试环境
- 测试工具：Locust 2.25.0
- 后端框架：FastAPI
- 模型：EAMNet
- 测试接口：POST /predict
- 测试图片：test.jpg

## 3. 本次测试参数
- 并发用户数：5
- 启动速率：1 用户/秒
- 测试时长：30 秒

## 4. 测试结果
- 请求总数：78
- 失败请求数：0
- 平均响应时间：353.82 ms
- 中位数响应时间：200 ms
- P95：1900 ms
- 最大响应时间：2276.76 ms
- 平均请求速率：2.65 RPS

## 5. 测试结论
本次测试共完成 78 次请求，未出现请求失败。
大多数请求响应时间较短，但 P95 和最大响应时间明显高于中位数，
表明本次测试中存在一定的长尾延迟。
后续需要结合重复测试和服务端资源监控进一步分析原因。
